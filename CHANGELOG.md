# Журнал изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Версии — [SemVer](https://semver.org/lang/ru/):

## [0.17.0-beta] — в работе

### Добавлено — творчество
- **Кнопки по активной программе**: виджет «Свои кнопки» сам показывает кнопки той программы, что сейчас открыта на
  компьютере (Mac, Windows, Linux на X11). Включается в настройках виджета (⚙ → «По активной программе»).
- **Готовые наборы кнопок** со стандартными сочетаниями: Photoshop / Photon Studio / Affinity, Lightroom Classic,
  Capture One, Krita, Clip Studio Paint, darktable. «mod» в сочетании — это ⌘ на Mac и Ctrl на Windows и Linux.
- **Lightroom Classic**: коллекции из каталога `.lrcat` показываются как съёмки — отмеченные, отклонённые, звёзды и
  цветные метки, прогресс по тому же правилу «отдано», что у Capture One. Каталог только читается.
- **darktable**: плёнки (импортированные папки) из `library.db` — тоже съёмки: звёзды, отклонённые, цветные метки,
  выгруженные (тег «darktable|exported»). Только чтение. Кнопка «Открыть в darktable» открывает плёнку в нём.
- **«Недавние работы»**: файлы, которые недавно открывали в Photon Studio, Photoshop, Krita и других программах
  (список Photon Studio и недавние документы системы); касание открывает файл на компьютере.
- **Референсы для художников**: картинки из папки «Изображения → TabDock Референсы» (подпапки — доски) на планшете
  рядом с холстом: приближение, отражение, чёрно-белый режим для проверки тонов, **таймер набросков** (30 с – 10 мин,
  по порядку или вперемешку) и **палитра** — касание кладёт HEX-код цвета в буфер обмена компьютера.
- Кнопка «Назад» на Android закрывает открытое окно, просмотр или отбор, а не всё приложение.

### Исправлено
- В карточке съёмки из Lightroom или darktable кнопка открывает нужную программу, а не Capture One; «Отбор и метки» —
  только для Capture One (он берёт превью из его кэша).

Проверено на Mac mini и HONOR Pad 9: наборы кнопок и переключатель «по активной программе», «Недавние работы» с
Photon Studio, референсы (таймер, Ч/Б, палитра → буфер обмена Mac), «Назад». Определение активной программы проверено
на Mac и Windows 11; переключение кнопок вживую — на MacBook (Finder ⇄ Заметки, около секунды). darktable 5.6.2 на
Windows 11 ARM: настоящий каталог читается, съёмка с обложкой, «Открыть в darktable». Lightroom Classic — только на
искусственном каталоге в автотестах (программы на тестовых машинах нет). Linux: определение активной программы только
в сессии X11 (в Ubuntu по умолчанию Wayland — там кнопки не переключаются).

## [0.16.0-beta] — 2026-11-18

### Добавлено — передача файлов
- **Большие файлы**: с телефона на компьютер файл идёт частями по 16 МБ, у каждой части проверяется SHA-256. После
  обрыва связи (Wi-Fi пропал, компьютер перезапустился) передача продолжается с того же места. С компьютера на телефон —
  докачка через Range. Ограничение — только свободное место (с запасом 0,5 ГБ), а не 2 / 4 ГБ, как раньше.
- **Папки целиком**: «Отправить папку» в приложении и перетаскивание папки (или «Выбрать папку…») в окне «Передача файлов».
  На той стороне появляется такая же папка с подпапками; повторная отправка той же папки не смешивается с первой
  («Фото (2)»). Пути вида «../» никуда не выводят.
- **Прогресс и скорость**: в приложении (экран «Файлы» и уведомление) и в окне на компьютере, там же — что принимается
  с телефона прямо сейчас. Кнопка «Отменить».
- Передача идёт в фоновой службе Android, поэтому не обрывается, когда приложение свёрнуто.
- Файлы с компьютера ждут телефон 48 часов (было 24).

### Исправлено
- Windows: если задачу TabDock остановить (или процесс завершится), сервер и значок в трее тоже закрываются, а не
  остаются висеть — раньше старый сервер мог занимать порт, а в трее появлялся второй значок.
- Android: после принудительной остановки приложение снова подключается к своему компьютеру, даже если он отвечает
  не сразу.

Проверено: файл 21,5 ГБ с планшета (HONOR Pad 9) на Mac mini и обратно — контрольные суммы SHA-256 совпали; докачка
после перезапуска сервера и после принудительной остановки приложения в обе стороны; папка с подпапками и кириллицей в
обе стороны (суммы совпали); Windows 11 — 50 МБ с обрывом и докачкой, папка с кириллицей. Не проверено: Linux на
реальном железе (только автотесты на GitHub).

## [0.15.0-beta] — 2026-11-15

### Добавлено — сервер на Windows
- Windows 10 и 11 (x64 и ARM): `install-windows.ps1` — venv, правило брандмауэра только для частных сетей, запуск при входе
  через Планировщик заданий, значок в области уведомлений с тем же меню, что на Mac и Linux.
- Состояние компьютера, музыка из любого плеера в системной панели Windows и громкость, быстрые действия, свои кнопки
  (сочетания клавиш, вставка текста), передача файлов, «Команды» из своих скриптов, календарь из `.ics`, хосты, Docker,
  здоровье дисков.
- HTTPS без `openssl`: самоподписанный сертификат создаётся на чистом Python.
- Проверки на GitHub теперь идут и на Windows.

Проверено на Windows 11 ARM64 (Parallels): установщик и автозапуск, значок в трее и его меню, состояние компьютера,
громкость и выключение звука с планшета, «сейчас играет» (Edge), пауза и продолжение, открытие программ с планшета
(окно открывается поверх), свои кнопки (вставка текста с кириллицей, сочетания клавиш), «Команды», скриншот,
перезапуск после сбоя, передача файлов в обе стороны (20 МБ, контрольные суммы совпали), HTTPS и подключение планшета.
Не проверено: каталог Capture One на Windows, извлечение USB-диска, сон.

### Исправлено
- Имена файлов с телефона очищаются одинаково на всех системах (оба разделителя пути).
- Панель на `localhost` открывается без задержки там, где браузер сначала пробует IPv6.

## [0.14.0-beta] — 2026-11-15

Проверено на планшете с сервером на MacBook: хосты и уведомления о них, пробуждение по сети, бэкапы, здоровье дисков,
сборки GitHub, git (fetch), настройки виджетов и долгое нажатие. Docker проверен только автотестами (на MacBook его нет).

### Добавлено — для админов и программистов
- Виджет «Хосты»: ping, HTTP или порт, уведомление, когда хост пропал или вернулся, пробуждение по сети (Wake-on-LAN).
- Виджет «Бэкапы»: Time Machine или свой файл/папка, предупреждение, если бэкап слишком старый.
- Здоровье дисков (SMART) в виджете «Диски»: `diskutil` на Mac, `udisksctl` на Linux.
- Виджет «Docker»: контейнеры, запуск, остановка, перезапуск, журнал.
- Виджет «Сборки GitHub»: последний запуск GitHub Actions по репозиториям (для закрытых — токен в `~/.config/tabdock/github-token`).
- Виджет «Git»: ветка, изменения, отставание и опережение, fetch и pull (`--ff-only`).
- Новые виджеты есть в пространстве «Система» у новых пользователей; остальные добавляют их кнопкой «Виджет».

### Безопасность
- С устройства можно действовать только с тем, что перечислено в настройках: указанные хосты, контейнеры из списка, указанные репозитории.
- git запускается без хуков и `core.fsmonitor` из настроек самого репозитория.

### Изменено
- Проверка обновлений больше не предлагает предварительные версии (pre-release): только проверенные релизы.

### Исправлено
- В окнах настроек клавиатура больше не закрывает поле, в котором печатаешь.
- После первой настройки на нижней панели появляется кнопка «Файлы».
- Time Machine: вместо «копий пока нет» — точная причина (не настроена, диск не подключён, нет доступа); дата берётся и при отключённом диске.
- В виджете «Git» репозиторий с неотправленными коммитами отмечен жёлтым.
- Подписи у полей в настройках новых виджетов.

## [0.13.0-beta] — 2026-11-09

**После обновления приложение нужно один раз переустановить и подключить заново**: у него новый ключ подписи,
и теперь подключение идёт по HTTPS.

### Безопасность
- Всё между устройством и компьютером идёт по HTTPS. Сертификат создаётся на компьютере, приложение запоминает его отпечаток из QR-кода.
- У каждого устройства свой ключ: список в панели, отключение по одному.
- Новое устройство начинает работать только после «Разрешить» в панели на компьютере.
- Менять QR-код (и отключать все устройства) можно только с самого компьютера.
- В README описано, от чего TabDock защищает, а от чего нет.

### Добавлено
- Настройка по долгому нажатию: на виджете включается режим правки или открываются его настройки, на нижней панели — выбор кнопок.
- Приближение при отборе: щипок и двойное нажатие, перемещение пальцем, более резкая картинка при увеличении.

### Исправлено
- Звёзды и цветные метки теперь записываются в Capture One: приложение находило не все альбомы. Проверено на реальном каталоге.

### Установка
- Установщик на Mac больше не пересобирает значок без необходимости, поэтому разрешения macOS не сбрасываются.
- Установщики подсказывают новый порядок подключения. На Linux добавлены `openssl` и уведомления о новых устройствах.

### Для разработки
- Автотесты (pytest) и проверки на GitHub для Ubuntu и macOS, сборка APK при публикации релиза.
- `server.py` разделён на `dock/core.py` и `dock/httpd.py`.
