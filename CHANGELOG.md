## [0.13.0-beta] — в работе

**После обновления приложение нужно один раз переустановить и подключить заново**: у него новый ключ подписи,
и теперь подключение идёт по HTTPS.

### Безопасность
- Всё между устройством и компьютером идёт по HTTPS. Сертификат создаётся на компьютере, приложение запоминает его отпечаток из QR-кода.
- У каждого устройства свой ключ: список в панели, отключение по одному.
- Новое устройство начинает работать только после «Разрешить» в панели на компьютере.
- Менять QR-код (и отключать все устройства) можно только с самого компьютера.
- В README описано, от чего TabDock защищает, а от чего нет.

### Добавлено
- Настройка по долгому нажатию: на виджете включается режим правки или открываются его настройки, на нижней панели — выбор кнопок.
- Приближение при отборе: щипок и двойное нажатие, перемещение пальцем, более резкая картинка при увеличении.

### Исправлено
- Звёзды и цветные метки теперь записываются в Capture One: приложение находило не все альбомы. Проверено на реальном каталоге.

### Для разработки
- Автотесты (pytest) и проверки на GitHub для Ubuntu и macOS, сборка APK при публикации релиза.
- `server.py` разделён на `dock/core.py` и `dock/httpd.py`.
