# Журнал изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Версии — [SemVer](https://semver.org/lang/ru/):
пока проект в бете, `0.x` — новые возможности, `0.x.y` — исправления.

## [0.14.0-beta] — 2026-11-14 (предварительная версия)

Собрана без проверки на устройствах, поэтому выходит как pre-release: «Скачать» по-прежнему ведёт на 0.13.0-beta.
Автотесты сервера проходят на macOS и Linux.

### Добавлено — для админов и программистов
- Виджет «Хосты»: ping, HTTP или порт, уведомление, когда хост пропал или вернулся, пробуждение по сети (Wake-on-LAN).
- Виджет «Бэкапы»: Time Machine или свой файл/папка, предупреждение, если бэкап слишком старый.
- Здоровье дисков (SMART) в виджете «Диски»: `diskutil` на Mac, `udisksctl` на Linux.
- Виджет «Docker»: контейнеры, запуск, остановка, перезапуск, журнал.
- Виджет «Сборки GitHub»: последний запуск GitHub Actions по репозиториям (для закрытых — токен в `~/.config/tabdock/github-token`).
- Виджет «Git»: ветка, изменения, отставание и опережение, fetch и pull (`--ff-only`).
- Новые виджеты есть в пространстве «Система» у новых пользователей; остальные добавляют их кнопкой «Виджет».

### Безопасность
- С устройства можно действовать только с тем, что перечислено в настройках: указанные хосты, контейнеры из списка, указанные репозитории.
- git запускается без хуков и `core.fsmonitor` из настроек самого репозитория.

### Изменено
- Проверка обновлений больше не предлагает предварительные версии (pre-release): только проверенные релизы.

## [0.13.0-beta] — 2026-11-09

**После обновления приложение нужно один раз переустановить и подключить заново**: у него новый ключ подписи,
и теперь подключение идёт по HTTPS.

### Безопасность
- Всё между устройством и компьютером идёт по HTTPS. Сертификат создаётся на компьютере, приложение запоминает его отпечаток из QR-кода.
- У каждого устройства свой ключ: список в панели, отключение по одному.
- Новое устройство начинает работать только после «Разрешить» в панели на компьютере.
- Менять QR-код (и отключать все устройства) можно только с самого компьютера.
- В README описано, от чего TabDock защищает, а от чего нет.

### Добавлено
- Настройка по долгому нажатию: на виджете включается режим правки или открываются его настройки, на нижней панели — выбор кнопок.
- Приближение при отборе: щипок и двойное нажатие, перемещение пальцем, более резкая картинка при увеличении.

### Исправлено
- Звёзды и цветные метки теперь записываются в Capture One: приложение находило не все альбомы. Проверено на реальном каталоге.

### Установка
- Установщик на Mac больше не пересобирает значок без необходимости, поэтому разрешения macOS не сбрасываются.
- Установщики подсказывают новый порядок подключения. На Linux добавлены `openssl` и уведомления о новых устройствах.

### Для разработки
- Автотесты (pytest) и проверки на GitHub для Ubuntu и macOS, сборка APK при публикации релиза.
- `server.py` разделён на `dock/core.py` и `dock/httpd.py`.
